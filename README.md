# Week 4 - Comprehensive Data Analysis, Reporting and Presentation using R

## Project Overview

This project integrates the data analysis work completed during Weeks 1, 2, and 3 into one comprehensive final project.

The Titanic dataset is used to demonstrate a complete data analysis workflow using R.

The project covers:

- Data cleaning
- Data preprocessing
- Exploratory data analysis
- Data visualization
- Statistical analysis
- Hypothesis testing
- Correlation analysis
- Predictive modeling
- Logistic Regression
- Cross-validation
- Model evaluation
- Data-driven insight communication

## Project Objectives

The main objectives are:

- Clean and prepare the dataset.
- Handle missing values.
- Identify possible outliers.
- Perform exploratory analysis.
- Create meaningful visualizations.
- Perform statistical tests.
- Analyze correlations.
- Build a predictive classification model.
- Evaluate model performance.
- Communicate findings clearly.
- Prepare a professional final report.

## Dataset

The Titanic dataset contains information about passengers who travelled on the RMS Titanic.

Important variables include:

| Variable | Description |
|---|---|
| PassengerId | Unique passenger ID |
| Survived | Survival status |
| Pclass | Passenger class |
| Name | Passenger name |
| Sex | Passenger gender |
| Age | Passenger age |
| SibSp | Siblings or spouses aboard |
| Parch | Parents or children aboard |
| Fare | Ticket fare |
| Embarked | Port of embarkation |
